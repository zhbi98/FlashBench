# 验证与测试

本篇说明框架的主机测试怎样运行、覆盖了什么，以及哪些部分还没有验证。修改框架后应重新运行主机测试。

## 主机测试

[sim_norflash.c](../test/sim_norflash.c) 在主机上用一块内存模拟 NOR Flash。模拟 Flash 带"忙"状态，并能按需要注入故障。在仓库根目录编译和运行：

```text
gcc -std=c99 -Wall -Wextra -Isrc test/sim_norflash.c src/flash_stress.c -o sim_norflash
./sim_norflash
```

每项检查打印一行 `ok` 或 `FAIL`。全部通过时最后打印 `ALL PASSED`，程序返回 0；否则打印失败的项数，返回 1。

## 覆盖范围

测试按模式分组。ROTATE 覆盖 Flash 忙时启动、遗留数据清理、擦除中途断电后的恢复和阻塞式驱动。READ 覆盖链路断开、位翻转、缓冲区越界、缓冲区不对齐和奇数长度少读。ENDURANCE 覆盖磨损失效次数、各扇区次数一致、断电后继续累计和耗时统计。

另有两组与模式无关。一组检查 `flash_stress_waiting()` 在各状态下的返回值，另一组检查非法配置：非法模式、缺少底层函数、扇区过小、测试区越界。

模拟 Flash 用下面几种故障来模拟真实的问题：

| 注入的故障 | 模拟的问题 |
| --- | --- |
| 每 N 次读翻转一位 | 偶发的传输错误 |
| 读函数多写一个字节 | DMA 越界 |
| 缓冲区不对齐时读错 | DMA 对齐处理错误 |
| 奇数长度少读一个字节 | 长度处理错误 |
| 所有读都返回 `0xFF` | Flash 没有响应 |
| 擦除若干次后有一位擦不掉 | 存储单元磨损 |

## 已验证的范围

| 对象 | 验证方式 | 结果 |
| --- | --- | --- |
| 框架 | 主机测试 | 全部通过 |
| port、run、mode、display 例程 | 主机上接模拟 Flash 运行 | 输出见使用说明 |
| spinor 例程 | 早期版本接模拟 SPI Flash 运行 | 当前版本未重跑 |
| freertos 例程 | 编译检查 | 未运行 |
| 真实硬件 | 无 | 需要在板子上确认 |

例程的运行覆盖了三种模式的启动和停止、READ 读到位翻转、ENDURANCE 擦写到失效后自动结束、测试区有别的数据时中止，以及运行中从 ROTATE 切换到 READ。[使用说明](usage.md#屏幕读数)中的屏幕和串口输出就取自这次运行。运行用的主机脚手架没有放进仓库。

SPI 时序和驱动对接只能在真实硬件上确认，主机测试不能代替。
